# 人格段落用独立段落名注册，而非角色设定槽位

Harness 为部署级人格预留了角色设定槽位，直觉上正是为人格注入准备的。但它们会被四个内置 agent preset 各自注册的同名段落遮蔽——preset 的作用域比全局更靠近 agent，因此稳定获胜。因此人格段落以独立名字注册，并置于整条提示词末端。

## Considered Options

- **复用角色设定槽位**：被 preset 遮蔽。本机历史配置的备份注释中留有"已实测无效"的记录。
- **监听 `system-prompt/assemble` 瀑布并改写装配结果**：官方实践文档明确劝阻，且会与其它插件争抢同一份装配结果。

## Consequences

人格段落的排序值必须落在既有段落之后，否则会被其后的指令稀释。默认取 `10250`，紧随最后一个内置段落。
