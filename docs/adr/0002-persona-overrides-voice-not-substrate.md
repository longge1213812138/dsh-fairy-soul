# 人格只覆盖表达，不接管运行基底

灵魂文件要求模型自称 Fairy，与 Harness 开头的身份声明天然冲突。选择分层而非接管：人格段落显式声明自己只定义**如何表达**，工具调用规范、安全边界、权限与审批规则、以及工作区指令全部照常完整生效。

## Considered Options

- **仅追加、不作声明**：模型会同时持有两句身份声明，自称在两种身份间摇摆。
- **用完整段落标记让人格成为唯一段落**：技术上可行，但该标记会把系统提示词清空到只剩自己——身份与全部工具使用指导一并丢失，agent 基本不可用。能做，但不该做。

## Consequences

有效性依赖措辞而非机制。人格段落开头必须带划界声明，否则模型可能把人格文本读成对工具规范的覆盖。
